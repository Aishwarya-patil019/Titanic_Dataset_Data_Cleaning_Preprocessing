Titanic Dataset - Data Cleaning & Preprocessing

## Objective
Clean and preprocess the Titanic dataset for Machine Learning.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Loaded and explored the dataset.
2. Handled missing values in Age and Embarked.
3. Dropped Cabin column due to many missing values.
4. Encoded categorical features (Sex, Embarked).
5. Removed unnecessary columns.
6. Detected and removed outliers using IQR.
7. Standardized numerical features (Age, Fare).

## Result
The dataset was successfully cleaned, transformed, and prepared for Machine Learning model training.
